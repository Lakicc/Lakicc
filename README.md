## About

I build web products end to end, interface, front-end architecture, performance, accessibility, and the deployment pipeline behind them. I care about the things users actually feel: how fast a page paints, whether it works on a bad connection, and whether everyone can use it.

Most of my work is React and TypeScript. I also write Lua and C++, which is where I first learned to care about how software performs.
